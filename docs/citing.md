# Citing RAPTOR

If you use RAPTOR in published work, please cite the paper describing it.

!!! info "Reference not final"
    The paper will be available on arXiv soon. This page will be updated
    with the full reference.

```bibtex
@misc{raptor,
  author        = {Minnozzi, Riccardo and Sagliano, Marco},
  title         = {Theoretical and Computational Advances in Birkhoff Pseudospectral Transcription for Aerospace Optimal Control},
  year          = {2026},
  eprint        = {XXXX.XXXXX},
  archivePrefix = {arXiv}
}
```

Please also state the RAPTOR version and the NLP solver you used (IPOPT,
SNOPT or WORHP), and cite the solver as requested by its developers.
