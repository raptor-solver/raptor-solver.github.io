# RAPTOR documentation page

Documentation page repo for the RAPTOR solver.

## Overview

This repo contains the source code for the documentation files for the RAPTOR solver. The objective is to have a single documentation framework where users can learn how to use and understand the tool. This repo will be used to display a website.

## Setup

To locally build and visualize the documentation use the environment.yml file to create a local conda environment with the required dependencies. 
After having a working conda distribution on your pc, simply run the following command from the repository folder:
```
conda env create --prefix ./.venv -f environment.yml
```
NOTE: if some changes are made to the .venv environment while developing the package, update the corresponding environment.yml file.
Once the environment is set up, you can build a local version of the documentation by activating the environment and running `mkdocs serve`.

## Example images and videos

The images and videos of the examples in `docs/assets/examples` are generated by running the RAPTOR examples. To regenerate them (for example, after changing an example), run from MATLAB, in the `scripts` folder:
```matlab
exportExampleMedia("path/to/raptor-matlab")
```
The figure exported for each example, and the examples recorded as videos, are listed at the top of `scripts/exportExampleMedia.m`. To export only some of the examples, list them as a second input, for example `exportExampleMedia("path/to/raptor-matlab", "07-orbitRaising")`.
